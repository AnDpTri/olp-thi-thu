Kept versus changed
- Kept the inherited runner/layout/template/session architecture and the existing command/tree/state flows after reading them. No wholesale rewrite was necessary. Rewrote README for 0.6.0.
- submit.js and vnoj.js remain byte-identical to the 0.5.1 VSIX. No exception or production network change.
- Hardened sample checks: rerun failed samples before submission; invalidate cached passes when sample data, compiler settings or timeout changes; invalidate on adding a sample. Changed source during checks or the language picker cancels submission instead of posting a stale snapshot.
- Compiler signatures use the actual saved file and its working directory. Java problems have separate build folders. Save failures stop a run. Compiled-source changes during compilation are detected.
- Added fallback child termination when Windows taskkill starts but fails, plus a one-shot stop guard for output floods. This fallback kills the owned child; descendants still depend on successful taskkill /T.
- Made Python's neutral template valid with pass. Serialized opening problems, avoided stale PDF attribution while rendering, restored the actual focused problem/phase after runs, and recorded failed compile/run/sample attempts.
- End/expiry waits for report delivery. A rejected stored cookie goes directly to the paste box. Editor-title buttons are scoped to kit source filenames AND kit problem directories. Explicit layout works even when automatic layout is disabled.
- Test scripts now use Windows system tar rather than Git tar, hidden isolated processes, and scoped cleanup fallback if WMI is unavailable. Existing leftovers were retained.

Features represented in source (host/UI behavior remains unverified here)
1. Reused editor groups: code left; input over output right; local PDF right-top with input/output beside each other below. Ends in code. olp.layout.auto=true.

5. olp.submit.checkSamples=true; one confirmation if samples still fail; at most one submission POST per click; tree submission times/verdicts/links/best result, scoreboard, re-poll action.
6. olp.timer.warnings=[60,30,10,5], warning/error clock background at <=10/<=5 minutes, live per-problem time.
7. olp.quick imports, opens A, offers Start; five recent links, remembered solution language; olp.duration=180.
8. Local-time report with UTC offset, counters and linked submissions; end/expiry writes, opens beside and copies report.
