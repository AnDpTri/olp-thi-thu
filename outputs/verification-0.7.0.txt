Known limitations:
- Export preserves the original PDF rather than rewriting PDF objects into new split PDFs. Correct cropped page PNGs, per-problem text, page boundaries and crop coordinates provide the separate statements.
- Manual page assignment is page-granular; automatic matching handles the real shared page-5 boundary.
- HTML parsing supports common explicit sample markup; unusual markup needs Companion/manual samples. Most PDF table layouts are deliberately not inferred from ambiguous flattened text.
- Idle/blur are interaction proxies, not attention measurements. Closed/crashed intervals have unknown real activity and are counted outside with a recording_gap marker. Pre-upgrade history cannot be reconstructed.
- Whole-file unified history diffs prioritize correctness over minimal hunks. Full lossless text edits/snapshots can make unusually large-output sessions exceed the normal low-tens-of-MB goal; artifacts themselves are capped.
- Existing compiler cache does not track header dependencies; delete .stamp after header changes. Windows taskkill denial falls back to killing the owned direct child, without a guarantee about grandchildren.
- Actual host behavior, UI readability and crash acceptance remain unverified until supervisor results arrive.

No git initialization, sub-agents, installation into the user's VS Code, production sign-in/submission, credential lookup, new production destination or deletion of old leftovers. vnoj.js has only the sanctioned guarded GET extension; submit.js is unchanged.
