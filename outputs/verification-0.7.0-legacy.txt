0.7.0 legacy-history follow-up after supervisor round 5

Root cause: olp.history bypassed reportText and directly called the old
timer.markdown renderer, producing seconds instead of the strict .000 format.
Separately, the new observation-only fallback treated an unrecorded old session
as unassigned time and lost its per-problem/phase allocation. This was a product
behaviour gap; the failing regex was NOT loosened.

Fixes:
- History reads the selected session's own detailed logs and uses the canonical
  report renderer, rather than the currently running session's recorder.
- Without detailed coverage, old focus/phase journal intervals reproduce the
  old per-problem allocation. Reports explicitly say:
  phien cu - khong co nhat ky chi tiet (Vietnamese accents/en dash in actual UI).
- True elapsed and limit come from original start/end/deadline. Unknown legacy
  idle/outside/output-split/other-file observations are displayed as a dash, not
  falsely measured zero. Old testing remains combined I/O.
- Continuing old sessions combine a journal-estimated prefix with observed
  post-upgrade intervals. A modern async startup delay is not labelled legacy.
- History copy/export target the viewed session. Historical export uses a local
  recorder view and never replaces or ends the active recording.
- Legacy ZIP: legacy=true, missingData, original legacy-journal.jsonl, old
  timing/results. Unknown historical source/input/output are unavailable rather
  than copied from today's kit files. Post-session snapshots are not labelled
  session-end source. Integrity verification remains valid for present evidence.

Tests:
- Strict v6-migrate assertion remains 00:02:00.000 / 03:00:00.000 and prints the
  full actual report on failure. It now checks A total/coding 00:01:00.000,
  legacy label, no NaN, unknown idle/outside, history clipboard, valid legacy ZIP,
  preserved journal, missing source and continued live edit capture afterward.
- Pure test checks old elapsed/limit and all three old phases against timer.stats,
  legacy ZIP/replay validity, no invented historical source, postdated snapshots,
  mixed old/new coverage, and modern startup classification.
- Python independently verifies the legacy archive and rejects absent text replay.
